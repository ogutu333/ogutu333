```console
┌──(deborah@cyberlab)-[~/lessons]
└─$ cat troubleshooting.log

"The exploit is broken."
→ It was the network.

"The tool isn't working."
→ Configuration issue.

"Why isn't my session connecting?"
→ Check the interface.
→ Check the IP.
→ Check the route.
→ Check the listener.

"This should be easy."
→ It wasn't.

LESSON:
Don't blame the tool before checking the setup.
```
